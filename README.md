#AniFix
AniFix is my second year Front end Web development module final Project.

More information is available on the wiki section of this Github page.

##Run

### Prerequisites:
* Node.js
* Ionic CLI v7 or above


***

### Installation

Install Ionic CLI 
```bash
npm install -g @ionic/cli
```

Clone and run
```bash
git clone https://github.com/KevinMongey/angular-anime-tracker.git
cd angular-anime-tracker
npm install
ionic serve
```
